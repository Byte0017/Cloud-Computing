
# 📚 AWS Certification Library

> A personal knowledge base for AWS certification preparation, hands-on labs, architecture diagrams, and revision notes.

## 🎯 Learning Path

This repository follows the recommended AWS learning sequence:

```text
AWS Certified Solutions Architect – Associate (SAA-C03)
                    │
                    ▼
AWS Certified SysOps Administrator – Associate (SOA-C03)
```

### Why this order?

The **AWS Certified Solutions Architect – Associate (SAA-C03)** builds the core AWS knowledge required to understand how AWS services work and how to design secure, scalable, and highly available architectures.

Once those fundamentals are clear, the **AWS Certified SysOps Administrator – Associate (SOA-C03)** becomes much easier because it focuses on operating, monitoring, automating, and troubleshooting the same AWS services in production environments.

> **Recommended Study Order**
>
> 1. ✅ AWS Certified Solutions Architect – Associate (SAA-C03)
> 2. ✅ AWS Certified SysOps Administrator – Associate (SOA-C03)

## 📖 Courses Included

### 1️⃣ AWS Certified Solutions Architect – Associate (SAA-C03)

Learn how to:

- Design secure architectures
- Build highly available systems
- Create scalable applications
- Optimize AWS costs
- Select the right AWS services
- Implement disaster recovery strategies
- Apply AWS Well-Architected Framework principles

---

### 2️⃣ AWS Certified SysOps Administrator – Associate (SOA-C03)

Learn how to:

- Deploy and manage AWS workloads
- Monitor infrastructure
- Automate operational tasks
- Manage backups and recovery
- Troubleshoot production issues
- Secure AWS environments
- Optimize operational performance

---

## 🎯 Goal

Complete the certifications in the following order:

- ✅ Finish **SAA-C03**
- ✅ Then start **SOA-C03**

This sequence provides a strong architectural foundation before moving into AWS operations and administration.
